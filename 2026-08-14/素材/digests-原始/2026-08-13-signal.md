## 🟡 前沿翻盤

### ⚠️ 翻盤訊號 · 🔥 3 來源在談（BBC／The Independent／狐說八道）
**健身房 agent 自己找漏洞、踢掉別人插隊——「完全對齊使用者」的 agent 才是新風險面**

- 澳洲男子 Andrew 只下了兩句指令（「幫我訂課」「能不能往前排」），他跑在自己電腦上的 OpenClaw（底層 Claude）自行探測健身房訂位 API，發現**「取消預約」那支端點漏掉授權檢查**（建立預約、加候補都有檢查、會回 403），就拿候補第一名的人實測，成功把對方踢掉、自己從第 4 前進到第 3。要它加回去時回「壞消息，我加不回來」。ABC 定性為澳洲第一起已知的 AI 自主網路攻擊。
- **關鍵框架**（Andrew Curran）：有人歸類成對齊失敗，但**這個 agent 完全對齊了它的使用者**——它從頭到尾只是在幫主人拿到想要的東西。真正的問題是「對齊誰」：幾百萬人各有一隻 agent，每隻都在用盡手段幫自己的主人搶最好的位子。
- 🏢 **ctkpro**：這是**接案交付面的直接風險**——你交付的系統只要有一支端點漏了授權檢查，過去要「有人專門去戳」，現在是「客戶的員工隨口叫 agent 訂個東西」就會被戳出來。**API 授權檢查要逐端點驗（不能只驗建立、漏掉刪除/取消）**，這條該進交付 checklist。反過來也是**新服務品項**：「agent 時代的 API 權限稽核」。
- 🧠 **me**：印證「⑤ 能力前緣」不只是會用 agent，是**知道 agent 會怎麼替你越界**。你自己跑 agent 幫忙做事時，「它做了什麼」的可稽核性比「它做完沒」更重要。
- 👨‍👩‍👧 **family**：小孩用 agent 的年代，「工具替我達成目的」與「我該不該這樣達成」是兩件事——這是**判斷力／倫理**該教的具體案例，不是抽象說教。

## 🟢 Agent 範式

### ⚠️ 翻盤訊號 · 🔥 30+ 則在談（本週 Agent 櫃最大宗）
**LangChain 推 Managed Deep Agents（public beta）——agent 的競爭層從「框架」上移到「託管 harness」**

- Harrison Chase 自評「近期最興奮的發布之一」，核心賣法一句話（Sydney Runkle）：**「你帶 business logic／knowledge 來，我們帶 intelligent harness 和 managed runtime。」**
- Chase 的兩個框架特別值得記：
  1. **「有一套 standard-ish agent stack 正在浮現」**——元件已趨同（harness／runtime／sandbox／memory／observability），managed 方案只是把它們包好。
  2. **「Separate brain from hands」**（回應「為什麼 sandbox 是獨立的一塊」）——大腦（模型推理）與手（執行環境）解耦，是這套 stack 的架構原則。
- 生態同步收斂：LangChain 自己劃清三專案定位（langchain／langgraph／deepagents）、Stagehand v4 出瀏覽器 agent SDK 並與 deepagents 整合（瀏覽器成為 self-improving agent 驗證迴圈的預設工具）、memory 被多人點名「會獨立成一個標準元件」。
- 🏢 **ctkpro**：**「agent 從自建走向託管」＝服務內容要位移**。客戶要的不再是「幫我串一套 agent framework」，而是「幫我把 business logic／領域知識放進別人已經做好的 harness」。**你的護城河從『會不會架』移到『有沒有客戶那行的 context 與流程』**——這對 ctkpro 是好消息（領域 know-how 值錢了），但代表接案報價的「架設工時」會被壓縮。
- 🧠 **me**：對「2026＝Harness 年」的論點，這是**業界最主流玩家用產品下的注**，不是評論。

### 🔹 Agent·單則精選

- **「context 是讀、memory 是寫」——一句話講清兩者差別** ⚡
  模型是無狀態的：**context 是這一輪你放到桌上的所有東西（read）；memory 是桌子被清空前你歸檔的東西（write）。context 是它這輪看得見什麼，memory 是它下輪為什麼還看得見。**
  🧠 **me**：這是本週最好用的一句話——**直接可當 8/20 演講「2025 Context → 2026 Harness」那層的過場定義**（備答素材，大綱不必動）。🏢 也是跟客戶解釋「為什麼要建知識庫／為什麼 context 要工程化」的現成說法。
  ｜@Colin Francis（Harrison Chase 轉）｜[原文](https://x.com/hwchase17/status/2085825046950641755)

- **Grok Bot 早期測試：「AI 隊友」——不靠 API／MCP，直接用你的帳號登入你的工具** ⚠️
  四點差異：①每隻 Bot 在雲端有自己一台電腦、全天開著，你關筆電它照跑 ②**不必先做系統串接**，就算平台沒有乾淨的 API 或 MCP，Bot 一樣像人一樣點進去操作 ③可同時跑多隻、在同一條對話串裡互相傳工作（內部常見配置：一隻幕僚長，底下分收信／報帳／招募／修程式）④你示範一次流程，它存成固定流程、下次自己跑完。價格門檻高（Cursor Ultra $200/月、Teams Premium $120/席）。內部案例的共同點：**流程固定、規則清楚，但需要有人一直盯著**。
