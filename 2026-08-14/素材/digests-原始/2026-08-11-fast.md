### 🔥 熱點卡 1 ｜ Claude Code「Auto mode 成預設」——不再逐次批准，改審結果 ⚡ 🔗

- **🏢 ctkpro**：這**直接打你 8/6 拍板的 Demo 引擎與團隊 SOP**——若團隊機器跟著升級，等於「預設放手讓 agent 自己跑」。你要的不是關掉它，是**趕在它變預設前把驗收標準寫下來**（哪些目錄可動、哪些不准動、做到哪停），否則等於把剩餘判斷權默默交出去。可直接餵進 P4「團隊怎麼交出 Context」那條卡住的線。
- **🧠 me**：這是 **9/3 演講《TL→EM》論述的一手證據**——「授權的分界線＝驗收標準」不再是你的比喻，是 Anthropic 自己把產品預設從「逐行批准（TL）」改成「事後審結果（EM）」。⚠️ 注意這則可安全上台引用：Simon Willison 的文＋Boris 本人推文都是一手，不像 Boris「90% 程式碼／五角色」那個二手轉述。

### 🔥 熱點卡 2 ｜ 放手之後的真帳單：review 成本 > 寫的成本、無限 Token 也撞天花板 ⚠️ 🔗
**🔥 3 人在談（宝玉 ×2、Simon Willison 引 Accenture）**

- **發生什麼**：宝玉點破一個反轉——**「以前寫程式成本高、review 成本低；現在反過來了」**，寫的人成本暴跌，但 review 的人要花更高成本才審得完，**開發者其實是把成本轉嫁給 reviewer**。另一則轉述一場實驗：**100 萬美元預算、20 多人團隊、不限量 Token**，結論是「人更累、**AI 成本比人還高**、效率提升最大的其實是『組織從 0 到 1 導入 AI』那一段、**組織架構仍是為人設計的，就算無限 Token 效率提升仍有明顯天花板**」。Simon 同週引 Accenture 的 "Tokenpocalypse"：企業開始拼命省 AI 花費。
- **🏢 ctkpro**：這是熱點卡 1 的**反面帳單**，兩張卡要一起讀——放手讓 agent 跑（auto mode）省的是「寫」，但成本會**整包移到你和 Aron 的 review 上**。對接案報價的意義很直接：**別再用「省下多少開發工時」報價**，真成本是 `cost per finished task`（含返工與審核工時）——這正好餵你 MEMORY 裡那條待 /ingest 的「投入 ROI 判準」。另外「效率提升最大的是 0→1 導入」＝**這正是 ctkpro 對客戶最有價值的服務位置**（客戶都還在 0→1），比替已上手的公司再優化更值錢。
- **🧠 me**：也是 TL→EM 論述的**必要平衡段**——上台只講「放手」會被打臉，要講「放手的代價是你得升級驗收能力」。
- 多方觀點：宝玉「成本轉嫁給 reviewer」｜百萬美元實驗「無限 Token 仍有組織天花板」｜Accenture 案例「企業開始縮 AI 開銷」

### 🔥 熱點卡 3 ｜ Prompt injection：從「已知防不住」到「疊層可壓到 ~0」，但 Skill 供應鏈才是破口 ⚡
**🔥 4 人在談（Boris Cherny ×2、swyx、Simon Willison）**

- **發生什麼**：Boris 說 **indirect prompt injection 在未見過的攻擊上可壓到 ~0——前提是疊夠多層**（模型訓練 ＋ input probes ＋ classifier 檢查）；他另指出「agent 造訪某網站、網站藏惡意文字」是**目前對人與 agent 最常見的攻擊手法**。swyx 則從另一頭喊話：**「定期刪掉你的 skills」**——在「這個 skill 改變我人生」的轟炸下，你的 skill 目錄本身就是攻擊面（他附了一篇 "dangerous release code was a skill"）。同週 Simon 連發多篇 OpenAI 誤攻擊 Hugging Face 的事故時間軸。
- **🏢 ctkpro**：auto mode 成預設（卡 1）＋ 攻擊面在 skill／網頁內容（本卡）＝**你的 agent 安全責任從「批准每步」變成「管好環境與 skill 清單」**。可立刻做的一件小事：**定期盤點與刪除沒在用的 skill／MCP**，比寫防護規則更有效。這也是接案時能拿出來講的差異化（客戶會問「AI 亂跑怎麼辦」）。
- **🧠 me**：防護不靠單點靠疊層——這個「多層防禦」框架同樣適用你設計團隊授權邊界。
- 多方觀點：@bcherny 疊層可壓到 ~0｜@swyx 反過來提醒 skill 本身是供應鏈風險、要定期刪｜Simon 用 OpenAI×HF 事故當現實案例
- 🔗 [Boris · 疊層壓到 ~0](https://x.com/bcherny/status/2085860677990883454)｜[Boris · 最常見攻擊手法](https://x.com/bcherny/status/2086520950259118464)｜[swyx · DELETE your skills](https://x.com/swyx/status/2086505938144616810)

### 🔥 熱點卡 4 ｜ Cloudflare 一週連發四彈：把整個網路改成「給 Agent 用」 ⚠️（建議④商業需求櫃接手）
**🔥 2 人在談但單源密集（小互 ×4、歸藏）**

- **發生什麼**：一週內連發——**WebMCP**（後台開個開關，網站一行程式碼不用改就能被 AI 直接操作）、**Kitesurf**（從零寫的 Agent 專用瀏覽器，CPU/記憶體省 3–7 倍，跑在 Workers 上）、**Cloudflare OS**（開源自家內部 AI 辦公平台，可部署到自己帳戶）、**Agent 錢包**（給 Agent 一個地址與帳號，讓它自己付 API 費用）。小互直呼「Cloudflare 可能是下一個 Nvidia」，盤後股價漲 16%。
