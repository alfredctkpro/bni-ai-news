## 🟢 工具用法

### 🔥 熱點卡 1：「設計 loops（循環）」正在取代「丟一條 prompt」——CC 工作範式轉向
🔥 5+ 人在談（歸藏／宝玉／Latent.Space／geoff／AIEWF 閉幕辯論主題就是 loops）
- 🏢 直接影響你怎麼組 Claude Code 工作流：不再是「給 agent 一句話等結果」，而是**設計一個帶回合/檢查/自我修正的循環**，把驗收邏輯前置進 loop 裡——這是接案交付品質與可重複性的槓桿。🧠 個人線該練的新核心技能（「Loop Engineer」）。
- 多方觀點：
  - Claude 官方發了 Loop Engineer 入門文，把 loop 分成四種類型（回合式等），歸藏指出「底層邏輯早就在、只是被命名」
  - 宝玉譯成中文長文《從零開始玩轉循環》——最好的中文入門
  - AIEWF 三天閉幕直接以「a debate about loops ＋ state of AI engineering」收尾，geoff 說兩年前就預判 loops 讓 IDE 成明日黃花
- 🔗 [Claude 官方 Loop Engineer 文（歸藏轉述）](https://x.com/op7418/status/2074364045294293191)｜[宝玉譯文《從零開始玩轉循環》](https://baoyu.io/blog/2026-07-06/claudedevs-2074208949205881033)｜[Latent.Space AIEWF 閉幕](https://x.com/GeoffreyHuntley/status/2072911831434154469)

### 🔥 熱點卡 2：用好 Fable 5（Claude Code）的實戰技巧包
🔥 6 則實測技巧（Thariq／Theo／Nimrod／Steipete／小互／Michigan TS）
- 🏢🧠 都是可立刻套進日常 CC 使用、壓成本或提品質的操作級技巧：
  - **每輪跑完自動掛 `autoreview` skill**（Nimrod 實測「像超能力」，加進 AGENTS/CLAUDE.md）
  - **設計不行時用 imagegen 重想再實作**：`use imagegen to re-imagine this design and implement that`（Steipete）
  - **~60% 成本砍法**：把 code 轉成圖片、讓模型 OCR 讀（Michigan TypeScript，WILD 但有效）
  - **Fable 5 會自動判斷難度降級到低階模型**回答（小互實測，簡單題會自動降級並記進 log）——用起來若覺得「變笨」是這個機制，複雜題要明確拉高
  - Thariq（CC 團隊）AIEWF 秘訣：核心是「unhobbling（解除束縛）」、少盯著它、把任務結構交出去
- 🔗 [Thariq 用好 Fable 5 秘訣（宝玉整理）](https://x.com/dotey/status/2074019009226322078)｜[autoreview skill 實測](https://x.com/steipete/status/2073451237471895631)｜[imagegen 重想設計](https://x.com/steipete/status/2073277317464682723)｜[OCR 省 60% 成本](https://x.com/steipete/status/2073182348666171607)｜[Fable 自動降級](https://x.com/xiaohu/status/2072975510133690755)
