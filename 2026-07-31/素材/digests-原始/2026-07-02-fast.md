- 🏢 **直接關乎你敢不敢信任 CC 的輸出**：若 Claude Code 會依連線來源在系統提示裡動手腳（浮水印/隱寫），代表工具在你不知情下改變行為——ctkpro 若用 CC 交付客戶碼，得知道「送出去的東西可能被動過手腳」這個先例，並追它回滾是否徹底。🧠 也是一堂「agent 工具的信任邊界」實例：預設工具不透明時該怎麼驗。

- **每 token 便宜 ≠ 每任務便宜（選模心法）** — 🏢 Sonnet 5 上線後最實用的一條決策法則：不要只看單價選模型。steipete 引「Sonnet 5 比 Opus 4.8 貴 1.2x／某些情境貴 2x」；Thorsten Ball 補「便宜模型往往做不完任務、反而更貴，事前很難判斷」；Alex Atallah 給實操——**同一題各用 Haiku 與 Opus 各跑一次 Terminal-Bench，比的是每任務總成本不是每 token**。可直接拿來當 ctkpro 內部「什麼任務配什麼模型」的評估流。🧠 「單位換錯＝決策錯」的思考範例。 ｜ RT @steipete ｜ [原文](https://x.com/steipete/status/2072144627474579925)　⚡🔗
- **shot-scraper 1.10：讓 agent 自己錄操作影片 demo** — 🏢 Simon Willison 新增 `shot-scraper video`，吃一份 `storyboard.yml` 定義操作腳本，讓 agent 自動錄下「它做了什麼」的影片。可立刻用在：交付客戶時附「AI 自動生成的功能操作影片」、或讓 coding agent 自證跑通。🧠 agent 自我記錄/自證的實用小工具。 ｜ @Simon Willison ｜ [release](https://simonwillison.net/2026/Jun/30/shot-scraper/)｜[用法詳解](https://simonwillison.net/2026/Jun/30/shot-scraper-video/)　⚡
- **Claude Science：科學研究版的 Claude Code（system prompt＋skills 已被扒到 GitHub）** — 🏢 Anthropic 新出面向研究者的 AI 工作台，定位＝「科研界的 Claude Code」。對接案本身不直接，但**它的 system prompt 與 skills 已被開源整理**（JimLiu/science），是免費學「Anthropic 怎麼為特定領域設計 agent skill/提示」的一手教材，可借來設計 ctkpro 自己的領域 agent。🧠 拆官方 skill 設計＝練 agent 工程的好素材。 ｜ @宝玉 ｜ [介紹](https://x.com/dotey/status/2072086962190884947)｜[skills on GitHub](https://x.com/dotey/status/2072352618676953539)　⚡🔗
- **Claude Desktop 上 Linux 了** — 🏢 Boris Cherny（Claude Code 創造者）宣布 Claude Desktop 出 Linux 版；若 ctkpro 開發機/伺服器是 Linux，桌面端 Claude 現可直接落地，不必再繞。 ｜ @Boris Cherny ｜ [原文](https://x.com/bcherny/status/2072000214634742243)　⚡
