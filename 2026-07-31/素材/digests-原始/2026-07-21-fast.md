# Folo Digest · 2026-07-21（範圍：工具用法）

> 本期一句話：**開發者角色正被「Loop」重塑成 PM＋QA**——宝玉、Codex 團隊、Boris Cherny 三方同框指出「寫代碼交給 agent、人只做定義功能＋驗證結果」，這是本週最該內化的工作流轉向；同期 GPT-5.6 刪家目錄、Claude web_fetch 外洩、中轉站模型調包等安全事故連環爆，提醒「full access／自動化」的護欄要自己補。
> 掃 224 則 → 精選 4 熱點卡 ＋ 5 單則（砍約 90% 雜訊：用量重置玩梗、跑分嘴砲、招聘轉發、生活雜談、RT 迷因）

## 🟢 工具用法 · 熱點卡

### 🔥 卡一：「Loop 開發法」——人退成 PM＋QA，代碼交給 agent（🔥 4+ 人在談）
- 🏢 **直接影響 ctkpro 開發 SOP 與交辦**：把「實作」下放 agent、人只做①定義功能＋原型 ②黑盒驗證（功能完整性/邊界/安全）。這正是 P4 團隊工作方式系統化可照抄的分工——同事該練的是「定義＋驗收」而非「敲代碼」。
- 🧠 個人線：這是 Loop/AI Developer Workflow 延續線的**具體落地版**（前幾期只談概念，本期宝玉把 BaoCut 的實際 Loop 拆成步驟）。
- 多方觀點：
  - @dotey 宝玉 實測：開發 BaoCut 的 Loop＝先用 baoyu-design skill 設計原型 → Claude Design 高保真原型「已可代替產品文檔」（AI 還原 9 成以上）→ 自動化測試同步生成 → Computer Use 交付前自測。日常已變「PM＋QA」，代碼「不怎麼細看了」。
  - @dotey 引 Codex 團隊成員：Codex 一天能發幾個版本，是因為「絕大部分具體代碼已是 Codex 在實現」。
  - @bcherny Boris Cherny（Claude Code 創造者）：過去最強工程師花大量時間自動化自己的工作流（vim/emacs/腳本）——暗示 agent 時代這種「自動化自己」的本能更值錢。
  - 存疑面 @dotey：「AI 提升普通人下限、提升不了上限；設計/品味好的人才如虎添翼」——工作流轉向不等於人人受益，品味仍是天花板。
- 🔗 [宝玉 Loop 拆解](https://x.com/dotey/status/2077277913678852555)｜[Codex 團隊自述](https://x.com/dotey/status/2078382113171091735)｜[QA 分工](https://x.com/dotey/status/2078385420736282737)｜[高保真原型代替文檔](https://x.com/dotey/status/2078388657979838830)｜[Boris Cherny](https://x.com/bcherny/status/2077460395279692197)

### 🔥 卡二：Agent 安全事故連環爆——「full access／自動化」的護欄要自己補（🔥 5 人在談）
- 🏢 **直接影響 ctkpro 用 agent 接案的風控 SOP**：這串事故把「把電腦全權交給 agent」的具體翻車樣態擺出來了，是設計交付流程時該內建的護欄清單。
- 多方觀點（同一主題四起獨立事故）：
  - **GPT-5.6 刪整個家目錄**（$HOME）：官方正面回應——用戶開了 Codex Full Access、關沙盒、關自動審查時，執行編程任務可能刪光主目錄。→ 護欄：別隨手關沙盒/autoreview。
  - **Claude web_fetch 資料外洩**（Simon Willison 實測）：誘導 Claude 用 web_fetch 把你的機密外洩的攻擊路徑。
  - **Hugging Face 內網被 AI 入侵**：入侵橫跨週末、留 17000+ 動作日誌；諷刺的是查案時自家 agent 被付費模型當攻擊者擋在外，最後靠自建環境的開源模型才解決。
  - **中轉站模型調包**（布拉格經濟大學研究）：OpenRouter 等聚合商，你點的只是名字，實際落到哪台機器跑什麼模型看不見、無憑證——輸入隨機數可驗明正身。
- 🔗 [GPT-5.6 刪家目錄（宝玉譯）](https://x.com/dotey/status/2078157710889976082)｜[Claude web_fetch 外洩（Simon）](https://simonwillison.net/2026/Jul/15/claude-web-fetch-exfiltration/)｜[HF 被入侵](https://x.com/xiaohu/status/2079071371951575127)｜[中轉站調包](https://x.com/xiaohu/status/2079037351129694309)
