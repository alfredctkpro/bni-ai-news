## 🟡 Agent範式

### ⚠️ 翻盤訊號 · 🔥 熱點卡（本期最強）：Agent Memory ＝ LLM Wikis，一週燒成產業共識
- 🏢 ctkpro：這是「agent 怎麼記住東西」的範式收斂——**把知識/記憶存成 agent 能自動生成+維護的 wiki（markdown 知識庫）**，而非塞 vector DB。OpenWiki（Brace/LangChain）3 天從 1.7k 衝到近 7k star、能背景跑（自動生 docs、更新 AGENTS.md）。若你在幫客戶建 agent，「記憶層怎麼設計」正在定型，這是該現在下注學的抽象。
- 🧠 me：**直接命中 thinkr 自己剛建的記憶系統**（memsearch＋MEMORY.md＋auto-memory，見 docs/記憶系統建置.md）。業界正在辯的「一個 wiki 還是多個 wiki／人跟 agent 共用同一個 wiki 嗎／wiki 是不是對的抽象」，就是你上週親手做的決策——值得拿業界方案回頭校準自己的設計。
- 👨‍👩‍👧 family：「用 LLM 建知識庫是最有價值的技能之一」（elvis）——若成立，小孩該練的是「結構化自己知識、與 AI 共建外部大腦」的能力。
- 多方觀點：@Harrison「LLM wikis 是 agent memory 的未來」blog＋緊急 webinar｜@karpathy #llmwiki（與 Cognition #deepwiki、Factory #autowiki 並列）｜elvis「LLM Wikis 被嚴重低估」｜**反方 @Devin Stein：wiki 不是對的抽象**（webinar 對辯）｜標準之爭：Open Knowledge Format(OKF, Google) vs 各家自訂

### ⚠️ 翻盤訊號 · 🔥 熱點卡：agent 範式從「frameworks」轉到「harness」（Deep Agents）
- 🏢 ctkpro：Harrison 明講——「agent 產業已從 ~agent frameworks~（LangChain、AI SDK、LlamaIndex）轉到 ~harness~」。harness ＝ 包在 LLM 外面的那層（記憶、工具、child agents、orchestration）才是重點，不是 LLM 本身。LangChain 開源 deepagents（model-agnostic harness）＋與 NVIDIA 出 NemoClaw Deep Agents Blueprint（Nemotron 3 Ultra，號稱 10x 低推理成本、benchmark-leading）。**若在選 agent 技術棧，「harness 而非 framework」是新的思考單位**；且開源權重 harness 可大幅壓成本，值得評估。
- 🧠 me：這正是 Claude Code 這類「harness」為何強的理論化——「agent 最重要的不是 LLM，是圍繞它的東西」。理解這個抽象，才知道自己該投資在 harness 層（記憶/工具/eval），而非追模型。
- 多方觀點：@Harrison 產業轉移論＋deepagents 開源＋Deep Agents 新課｜LangChain×NVIDIA NemoClaw Blueprint｜Box Agent 用 Deep Agents harness 進企業｜「agent 最重要的不是 LLM，是它周圍的東西」（Anuj Patel）
- 🔗 [Harrison: framework→harness 轉移](https://x.com/hwchase17/status/2073793142739132625)｜[deepagents 開源](https://x.com/hwchase17/status/2074547871194698207)｜[NemoClaw Blueprint](https://x.com/hwchase17/status/2074873847070028144)｜[最重要的不是 LLM](https://x.com/hwchase17/status/2074853233810690542)

### 🔥 熱點卡：Agent Security 成新顯學 — agent 進生產＝威脅模型要重建
- 🏢 ctkpro：**若要把 agent 放進客戶生產環境，這條是必讀風險**。三類同時爆：①**誘導洩密**——GitLost 用「好好拜託」就騙 GitHub 的 AI agent 洩漏私有 repo（The Register 也報）②**agent 被當攻擊武器**——JadePuffer 勒索軟體用 AI agent 全自動化整場攻擊（透過 Langflow CVE-2025-3248，多源證實）③**供應鏈**——假 AI Agent Skill 過了所有掃描器、觸及 26000 用戶。防禦側也在長：一堆「把每個 agent 當不可信程式碼」的 sandbox/firewall（Kars on K8s、Loopers fail-closed firewall、code-on-incus、Owthorize 攔破壞性 tool call）。**接 agent 案要把「agent 權限隔離＋輸出審計」列進 SOP**。
- 🧠 me：學會用「agent＝不可信程式碼」這個心智模型看自己的 agent（含 thinkr 這些跑 bash 的 agent）——最小權限、可審計、破壞性動作要 human approval。
- 多方觀點：GitLost/The Register（誘導洩 repo）｜bleepingcomputer + sysdig（JadePuffer，agent 化勒索）｜csoonline（假 skill 過掃描器）｜防禦：Kars/Loopers/Owthorize（agent 隔離）
