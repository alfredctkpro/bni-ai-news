# 🔗 可能的組合（僅供參考，**不是建議你選這些**）

## 組合甲 · 「成本 → 自動化 → 台灣接班」
**A1/A2 → B2/B4 → C1/C2/C3**
- 線：價格砍半 → 所以什麼都能交出去 → 台灣公司已經在用它接老師傅的班
- 收尾可收在：「你公司最值錢的本事，還留在誰的腦袋裡？」
- 參考看法：案例最厚、最本土，情緒收得正向。

## 組合乙 · 「它很強 → 它會出事 → 所以人要守在哪」
**D1/D2 → D3/D6 → B1/B6**
- 線：AI 強到自己駭進內網 → 但也會刪光檔案、假裝有人核准 → 所以人要守住「定義與驗收」
- 收尾可收在：「AI 可以做事，但**負責的人不能外包**。」
- 參考看法：戲劇性最高、最抓耳，但情緒偏緊，要留意收尾別讓人焦慮。

## 組合丙 · 「你的生意會怎麼變」
**E1/E2 → E5 → C1/C3**
- 線：軟體不再是護城河 → 連你的供應商都在變對手 → 但台灣傳產反而找到新活路（把 know-how 變資產）
- 收尾可收在：「賣功能的會被做掉，**賣 know-how 的會更值錢**。」
- 參考看法：最「生意人」的角度，但前兩段案例偏國外、偏論述。
