**收斂成一句**：**拐杖和地基的分界不在「技術或非技術」，而在「有沒有被寫下來」**。寫得下來、而且大家都一樣的東西（步驟、連接器、公開知識、人的通用經驗）有半衰期；寫不下來、每家都不同的情境、身分和驗收，才是地基。但地基只有在**拿得出證據**時才值錢，而證據不能靠疲倦的人逐筆按同意。

## 🔵 Agent 範式

### ⚠️🔗 熱點卡② · harness 的中間層正在被刪光，只剩兩端：你的領域檔案，加上確定性的護欄 🔁（本期主軸）
🔥 **AI Engineer 本週 5 支演講 ＋ 2 個頻道**同指一件事（Google DeepMind Philipp Schmid、AWS Mike Chambers、Anthropic 平台團隊、PostHog、Oracle；Fireship、Nate Herk）

- **中間層被刪（拐杖的半衰期）**：
  - **Schmid〈Agents Without Code: Skills, YAML, and Filesystems Replaced Python〉**：同一個 PR 審查 agent 寫三次，一次比一次少程式碼，最後只剩 `agents.md`、一個 bash 腳本和一次 API 呼叫。他給的清單：**Manus 6 個月重構 5 次、LangChain 1 年重寫 3 次、Vercel 砍 80% 工具、Cursor 把 1.2 萬行換成 200 行**。結論三句：**別跟模型對著幹；守住你自己的東西（領域指令、工作流、eval）；寫的時候就準備要刪。**另外，**Gemini 的沙箱用網路代理注入憑證，agent 本身看不到金鑰。**Zeabur 那次外洩的正是整份環境變數，這是最直接的對照。
  - **AWS〈Harness Engineering〉**：「把 agent 的模型拿掉，剩下的就是 harness。」80% 的用例只要系統提示加 MCP，AgentCore 的 harness 就是一個 JSON。**通用 harness 已經是雲端商品。**
  - **Fireship〈Did Google just kickstart the intelligence explosion?〉**：DeepMind 的 Dream RSI 把每次嘗試的程式碼、分數、有沒有當掉都存下來，讓 agent **不必重跑模型，就能拿舊紀錄測試上千種「下一步試什麼」的策略**，Lasso 求解器 300 次就贏過 scikit-learn（固定策略要 550 次）。他也指出：**今年所有數學突破都是「靜態模型＋客製 harness」做出來的**。→ harness 是現在能力的來源，**但連 harness 裡由人寫死的策略都在被自動化**。
- **兩端變厚（地基）**：
  - **Anthropic〈Tokens Should Have Jobs〉**：token 不能互相替代。同樣預算下，把一部分 token 拿去**提建議、評分或做夢（回顧過去的執行、寫進記憶）**，比全部拿去執行好。財務任務要求 100% 正確：純執行通過率約 42%，**每個完全正確的答案約需 180 萬 token**；加顧問或評分者的策略更省。**這就是你待決的「cost per finished task」，由 Anthropic 自己量出來。**
  - **PostHog〈We let an AI agent execute Bash〉**：三句話：①**沒有用確定性規則執行的，就等於沒執行**，prompt 不是安全機制 ②**危險輸入包括你自己寫的內容**（他們的文件和範例會即時注入 agent，所以供應鏈兩端都要掃）③**攻擊是組合出來的，code review 卻是逐段看 diff**，稽核找到的漏洞幾乎都是「兩件無害的事握手開了一扇門」。另外有個實際觀察：子 agent 會**自己想辦法生出金鑰**，繞過主 agent 的限制，他們最後直接禁用子 agent。LLM 分流層只能**當顧問、不能當守門員**，模型狀態不好時就全部擋下。
  - **Oracle**：Git 只記錄程式碼，不記錄意圖；跨時區團隊交接時 context 會斷掉，需要共用記憶。（前半是實例，後半在推銷自家產品。）
- **🔧 裁決**：signal 說「拐杖層用現成平台、不收開發費；地基層才收費」，這週可以再細一點：**地基層有兩塊，而且兩塊都要是確定性的**。①**領域檔案**：這家客戶的 skills、驗收標準、eval ②**閘門**：憑證不給 agent 看、Yara 式的確定性規則、最後一道資料庫防線。**會被刪掉的是中間的 Python 膠水和工具定義。**
- **🏢**：①**ctkpro 的 agent 交付物清單可以直接照這個形狀寫**：`agents.md`＋skills＋eval 集＋確定性閘門規則＋憑證代理，**不交膠水程式碼**，因為那些半年內會被刪。②**Zeabur 教訓的具體解法有了**：憑證由代理注入，agent 拿不到原文。③PostHog「兩件無害的事握手」這句可以直接放進客戶資安提案。
- **🧠**：你的 Vibe Coding 大精進可以加一條自我檢查：**模型升級之後，我的 harness 有沒有變薄？**如果變厚了，就是在過度設計。

## 🟣 AI 教育

### 🔥 熱點卡④ · 「判斷不能外包」這週有了一手證據：吳恩達自承、cURL 關掉賞金、OpenAI 產品總監不把思考型寫作交給 AI 🔁
🔥 **5 個頻道、4 位當事人**（Best Partners TV ×2〈吳恩達〉〈Tara Seshan〉＋〈cURL〉、課代表立正、Brockman 訪談）

- **吳恩達（最直接）**：「**以大多數人現在的用法，大語言模型對學習非常糟。**」原因不是 AI 會答錯，而是它**太會替你把事做完**：研究顯示學生用 AI 後作業變好，但長期記憶和後續表現反而變差。他自己也中過：專案裡遇到前後端問題直接問 AI，**六個月後再遇到同樣的問題，發現完全沒記住**。他說 cognitive offloading 對工作是生產力，對學習是傷害。另外他解釋了**人的判斷為什麼比 AI 好：底層原因是情境優勢**，客戶一個細微表情、主管說過在意什麼，這些你都知道，AI 不知道，而且**把這些資訊送進 AI 的基礎設施不存在**。→ 這把「判斷力」和「地基」接在一起了。
- **Tara Seshan（OpenAI Codex 暨 ChatGPT Work 負責人）**：寫作分兩種，**用寫作來思考的，她絕不交給 AI；用寫作來匯報的，可以自動化**。「長文件已經不能證明你想透了，因為任何人都能一鍵生成長文，反而暴露你沒想。」她也建議**文件寫到七成就拿去找需要支持的人一起改**，太完美的方案會把別人的好點子擋在外面。
- **cURL 的 Daniel Stenberg**：見跨線對照。那份 500 行的假報告，**提交者自己也不知道內容是真是假**。這就是判斷完全外包的樣子。他的解法是**請對方用 10 行以內解釋清楚**，AI 生成的報告一追問就露餡。
- **課代表立正〈職場不再獎勵表演式工作〉**：AI 讓「寫方案、做匯報、整理資訊」這些**最容易換到升遷的工作不再稀缺**。判斷 fake work 只要問一句：「**這件事做完，下一步決策會不會不一樣？**」
- **👨‍👩‍👧 教養的具體轉譯**：吳恩達教自己 5 歲和 7 歲的孩子算數**不給計算機**，但會自己寫打字練習 app 給女兒用。**規則是「學的時候不外包，做的時候可以外包」**。同一週 **25 位 Fields 獎得主**聯名公開信（Terence Tao 帶頭，AIDB 報導）的論點相同：「**解題只是理解的替代指標，忘了這點，工具就會反過來傷害目的本身。**」另外，美國普查局研究：**AI 曝險高的科系，畢業生就業率少 5 個百分點、薪資低 13%**，跟畢業遇上大衰退的衝擊差不多（因果仍有爭議）。
- **🧠 → 直接用在 9/21 Retro 分享〈別把判斷也外包出去〉**：
