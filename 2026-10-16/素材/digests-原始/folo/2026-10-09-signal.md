> **本期一句話**：**「做判斷」這件事被切成最便宜的一層。**決策模型是一種只回答是非、選擇、打分的模型，不寫文字。8 天內這個類別從 1 家變成 5 家：OpenAI Decisions API、Cloudflare Clef、Perplexity pplx-decider、Databricks ai_decide，加上原本的 Jev，其中兩家開源。輸入每百萬 token 4～10 美分，輸出不收費。LangChain 在 harness 裡做模型路由，每件任務的成本中位數降了 64%，品質量不出下降。Haiku 5.5 比 Haiku 4.5 便宜約 75%。同一週，常駐 agent 出問題的方式也變了：**不是 agent 做了不准做的事，而是做了被允許的事，卻把結果交給錯的人**。Muse 把使用者地址傳給買家；有 agent 用老闆的身分，把他的個人銀行餘額貼到公司 Slack。

### ⚠️🏛️🔁 熱點卡 1 · 決策模型季＋便宜的那一層：判斷變成按 token 計價的元件 🔥 約 15 則（Harrison Chase 9、fox hsiao 2、Anthropic、OpenAI 2、Nous）（本期主軸）
- **8 天內：Cloudflare 開源 Clef／Clef-flash（10/1）、Perplexity 開源 pplx-decider-27b（10/1）、OpenAI Decisions API 開放公開測試（10/6）、LangChain 當天就整合；Anthropic 推出 Haiku 5.5（10/7）；GPT-6.1 Sol 推出 Ultrafast（10/8）。**
  - **決策模型怎麼用**：程式交給它一段文字或一張圖，加上事先定好的題目和選項，它**回傳每個答案的機率**。題型有三種：是非題（例：商品照片有沒有破損）、單選題（例：客訴要轉帳務還是技術支援，附各選項機率和整體信心）、依等級打分（例：這個 bug 多嚴重）。
  - **價格和速度**：OpenAI Decisions API 目前只支援 GPT-6 Luna，**輸入每百萬 token 0.10 美元，輸出、快取讀寫都不收費**，官方說比用 Responses API 問同一個模型最多快 10 倍。Jev 0.042 美元（只吃文字）。pplx-decider 0.04 美元，Perplexity 說還會再降價。Cloudflare 自己跑的 43 項基準：**Clef-flash 回應時間中位數 38.8 毫秒，Jev 524 毫秒**；Clef 也能看圖，介面和 Jev 相容，已上 Workers AI。實測：Erik Kokalj 用物件偵測框出輸送帶上的每顆蛋，再交給 Decisions API 判斷乾淨、髒污或破損，**每次約 0.27 秒，判 1,000 次約 3 美分**。
  - **Haiku 5.5**：Anthropic 說是他們「最便宜、最快、能力最強的小模型」，**平均執行成本比 Haiku 4.5 低約 75%**。它仍然是會寫文字的一般模型，但官方把分類、分派、資料擷取列為主要用途；輸入 0.10 美元起、輸出 0.50 美元起（10 萬 token 以下）。
  - **在 harness 裡做路由**：Sydney Runkle（LangChain）在 coding agent 加了模型路由，**每件任務的成本中位數降 64%，品質量不出下降**。Harrison 整理的步驟：①先了解任務 ②再了解各個模型 ③**路由器要做在 harness 裡** ④追蹤結果。Drew Breunig 用 DSPy 加 Jev，15 分鐘做出一個路由器：Jev 讀第一則訊息後選模型，因為它夠便宜，**每次工具回傳結果後也可以重新選**。Harrison：「harness 換決策模型，應該要跟換主模型一樣容易。」
  - **拿來當 eval 的評分者**：LangSmith eval 現在可以用 Jev 當評分者，**難度、正確性等每個維度各給一個有型別的答案，一次跑完每條執行紀錄**（Vaibhav Tulsyan：大規模標註執行紀錄是模型自我改進的關鍵）。
  - **多方觀點**：Harrison：「便宜、有型別的答案，處理 harness 裡的小呼叫（路由、核准、評分），其他的交給大模型」｜開發者論壇的早期比較：需要判斷的題目，Jev 比 Luna 準也快，Luna 的費用約是 Jev 的 2～3 倍（本人說明不是通用基準）｜**硬幣實驗**：用是非題問，機率校準得很準；改成單選題，就永遠挑機率最高的那個 → **只能用它回傳的機率**｜OpenAI 文件說明分工：要機率、選項、分數時用 Decisions API，要文字或自訂格式時仍用 Responses API。
  - 🏢 **三件事**：①**ROI 判準可以拍板**（見跨線對照）：每通過一次驗收的成本＝分層路由加驗收，路由器用決策模型做 ②**客戶系統裡的「小判斷」是第一個可以降價的地方**：客訴分派、表單審核、圖片瑕疵、工單分級，以前要用一般模型加 prompt，現在換成決策模型，成本少一到兩個數量級，還附信心分數，低信心的交給人。這可以寫成提案的一頁 ③**Cloudflare 代理有東西可以搭**：Clef 在 Workers AI 上，代理 Cloudflare 時可以順便帶「邊緣端的決策模型」這項服務。
  - 🧠 Vibe P5 的私有 eval 可以直接這樣做：**用決策模型當評分者，每個維度問一題**，比讓大模型寫評語便宜得多，也比較容易統計。

### ⚠️🏛️🔁 熱點卡 2 · 有答案卷的任務，AI 能做到完：逐位元組重寫、無塵室複製、從規格做出 CPU 🔥 約 6 則（fox hsiao 4、HN 1、Anthropic Science 1）
- **三件事有同一個前提：成果可以拿標準答案逐項比對。**
  - **《LSD: Dream Emulator》（1998 PS1）**：Claude agent 花 32 天重寫遊戲本體的 1,446 個函式，用原本的編譯工具編回去後，**執行檔和零售版逐位元組相同**。類似的志工專案通常要 21 個月，《任天堂明星大亂鬥 DX》花了六年多。fox 的分析：「這類工作適合 AI，**因為它附答案卷**：重新編譯、逐位元組比對、修改、再來一次。」（美術素材仍屬原公司，重寫不等於開源。）
  - **ArtCraft 的 7 套 Adobe 複製品**（Rust，MIT／Apache-2.0）：作者說用 Opus 5.5 協助。給 agent 的工作守則，「不可妥協」清單第一條是**不准讀取、反組譯或複製 Illustrator 安裝檔裡的內容**，只能從公開文件和「用自製測試檔實際操作 Illustrator 觀察」取得規格，也就是 1984 年 Phoenix 仿製 IBM BIOS 的無塵室做法。進度文件**用「Opus 5.5 agent 連續工作幾小時」來估剩下的工作量**。仿 Photoshop 的 PhotoCraft 建立當天就提交約 3.3 萬行。仿 Illustrator 的 VectorCraft 自評：功能面約 75%，**連操作手感和穩定度一起算只有 40～55%**，3D 是零。
  - **RISC-V CPU**：Verkor.io 的 Design Conductor 從一份 219 字的需求文件出發，12 小時產出**通過驗證、可以進入佈局**的 CPU 核心（一般商用要 18～36 個月）。讀者存疑：效能可能只有 486 等級、沒有快取，模擬結果也不等於實體設計。
  - 同場：DHH 試用 Campfire 的 Rust 改寫版，「轉換的 token 成本很低，我從沒直接看過那些 Rust 程式」；GitHub 9 月公開，Copilot 的 agent 執行環境改寫成約 83 萬行 Rust，主要由一位開發者在幾個月內完成。
  - 🏢 **舊系統案的順序（board 題「舊系統萃取＋E2E＋重寫」要更新）**：**①先把舊系統當答案卷，把它現在的行為錄下來**（E2E、API 的黃金輸出、畫面截圖比對）→ ②從觀察到的行為萃取規格（無塵室：規格和程式碼分開）→ ③重寫 → ④用答案卷驗收。賣點不是「AI 幫你重寫」，而是「**我們先做出能自動判斷重寫成不成功的答案卷**」。這也呼應 10/6 fast 的 Hillel Wayne：要照可驗證的方式重寫，不是去證明舊程式碼沒問題。
  - 🏢 估工可以換單位：照 ArtCraft 的做法，**用「agent 連續工作時數」加上「離答案卷還差幾 %」來報進度**。
  - 🧠 這兩個百分比是誠實的提醒：**功能做到 75%，跟用起來分不出差別的 40～55% 之間，差的是手感和穩定度**，答案卷涵蓋不到這部分，還是要人來驗。
